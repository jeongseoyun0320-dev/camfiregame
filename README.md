# 🐰🔥 토끼 병사단의 야영지 (Camfire Game)

> 토끼 병사단이 되어 60초 안에 멧돼지를 사냥해 굽고, 쓰러진 동료를 살릴 약초를 캐 약을 만드는 **8비트 세피아 톤 타임어택 어드벤처**

▶ **플레이하기: https://camfiregame.vercel.app/**

설치 없이 브라우저에서 바로 플레이할 수 있는 HTML 파일 하나짜리 픽셀 아트 게임입니다.

---

## 📖 스토리 흐름

```
PART 1 멧돼지 사냥 → 모닥불 잔치 → 동료 토끼가 쓰러짐! → PART 2 약초 · 절구 → 약병 전달 (엔딩)
```

## 🎮 게임 방법

### PART 1 — 멧돼지 타임어택
- **60초 안에 멧돼지 15마리**를 구우면 성공
- 밧줄 달린 **작살**을 던져 멧돼지를 맞히면 끌고 돌아옵니다 (가까이 가면 도망가요)
- 모닥불 옆에서 굽기: **3초면 익고, 12초가 넘으면 탑니다**
- 고기를 여러 개 모아 한 번에 구우면 빠릅니다

### 이야기 연출
- 성공하면 다 같이 잔치! 고기가 한입씩 줄어 뼈만 남아요
- 잔치가 끝나면 모닥불 옆 토끼가 쓰러지고, **약초 말풍선**이 떠오릅니다

### PART 2 — 약초 타임어택
- 화살표를 따라 오른쪽 숲 속 **약초 전장**으로 이동
- **도구 걸이**에서 작살을 **괭이**로 바꾸면 시작
- **60초 안에 약초 25개**를 캐서 절구로 약을 만들기
- 다 빻은 약은 **5초 안에 꺼내야** 해요 — 늦으면 약효가 떨어져 못 씁니다
- **빨간 독버섯**을 캐면 잠시 어질어질 (시간 손해)

### 엔딩
- 약병을 얻으면 모닥불로 돌아가 쓰러진 토끼에게 전해주세요 💊 → ♥

## ⌨️ 조작법

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Space / J | 작살 던지기 (PART 1) · 괭이질 (PART 2) |
| E | 굽기·꺼내기 / 도구 교체 / 절구에 넣기·꺼내기 / 약병 주기 |
| Enter | 시작 |
| R | 다시 시작 (PART 2에서는 PART 2만 다시 도전) |

## ✨ 특징

- **이미지 파일 0개** — 토끼, 나무, 불꽃까지 전부 글자 도트 지도와 코드로 그림 (외곽선 자동 생성)
- **22색 제한 세피아 팔레트** — 색을 섞지 않고 팔레트 안에서만 밝기를 바꾸는 8비트 감성
- **디더링 조명** — 흔들리는 모닥불·횃불 빛, 나뭇잎 사이로 내려오는 햇살 줄기
- **파티클** — 불씨, 연기, 포자, 햇살 먼지, 약초 부스러기
- **넓은 월드 + 부드러운 카메라** — 화면 3배 넓이의 맵
- **최고 기록 저장** — 브라우저 localStorage에 PART 1 / PART 2 기록 저장

## 🛠 기술 스택

- HTML5 Canvas + 순수 JavaScript (라이브러리 없음)
- 192×108 저해상도 캔버스를 정수배로 확대 (픽셀이 선명하게)
- 배포: [Vercel](https://camfiregame.vercel.app/)
